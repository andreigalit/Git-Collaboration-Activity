# Git Collaboration Activity

## Project Description

This project demonstrates how developers collaborate
using Git and GitHub.

## Purpose

To practice version control, branching, committing,
pull requests, code reviews, and resolving merge conflicts.

## How It Works

Two developers work on separate branches, contribute
changes, review each other's work, and merge their
contributions into the main branch.

## Git Best Practices

Here are some important practices when using Git:

1. Write clear and meaningful commit messages.
2. Commit changes regularly.
3. Create separate branches for new features.
4. Pull the latest changes before starting work.
5. Review code before merging pull requests.
6. Always test your changes before pushing them.
